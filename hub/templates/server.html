Serve the hub over https: the paths of a certificate chain and its private key, both PEM (from Let's Encrypt, say: fullchain.pem and privkey.pem). The hub reads them when it starts. Leave both empty for plain http, behind a proxy that does https.

Only shown to an admin browsing from the server itself. Flags win over this: --tls-cert and --tls-key.
