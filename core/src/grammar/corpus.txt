caps lock and the last lead reset at the start of each run (a body, each argument), so arguments decode on their own.
Evaluation runs on an explicit continuation stack, never native recursion.
A call in tail position replaces its frame instead of pushing one:
text before it is already in the frame's output, which the call continues;
Any other call pushes frames, up to the depth limit, past which evaluation stops with an error.

The game is a memory palace built on gematria.
